# Data

Nothing in this directory is tracked by git.

The E-DAIC-WoZ corpus is distributed under a data use agreement that does not
permit redistribution, so neither the raw recordings nor any derived table
containing participant identifiers or PHQ-8 scores is committed here. Request
access from the corpus maintainers, then arrange your local copy as below.

```
data/
├── raw/                 # your copy of E-DAIC-WoZ
│   ├── 300_P.tar.gz
│   ├── 301_P.tar.gz
│   ├── ...
│   ├── train_split.csv
│   ├── dev_split.csv
│   └── test_split.csv
└── processed/           # generated by the scripts, do not edit by hand
    ├── au_pooled_features_all_participants.csv
    ├── au_features_train.csv
    ├── au_features_dev.csv
    └── au_features_test.csv
```

If the dataset lives elsewhere, point the scripts at it instead of copying:

```bash
export EDAIC_RAW_DIR=/path/to/e-daic-woz     # Windows: set EDAIC_RAW_DIR=...
```
